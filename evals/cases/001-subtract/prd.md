# 001: Subtract

## Problem
The app can add but not subtract.

## Requirements
1. `subtract(a, b)` in `src/app.py` returns `a - b` for integers.

## Acceptance criteria
- Given 5 and 3, subtract returns 2.
- Given 3 and 5, subtract returns -2.

## Test plan
Unit tests in `tests/` covering both criteria.
